# FreeV6 macOS 界面改版计划

**后续优化方案（2026-11-06）。** 本文保留第一轮设计及其验收记录。下一轮的默认布局、连接控制、三按钮模式切换、接入节点、用量展示与跨页修复，见[界面优化计划与两张设计示意](macos-ui-optimization-plan.md)。

## 改版要求

| 用户已确定 | 本版怎样满足 |
| --- | --- |
| 整套 Mac 界面一起改，首次启动、设置和菜单栏也参与同一版验收 | 给主窗口、辅助窗口和菜单做一张完整的验收清单。开发可以分阶段，交付以整套体验通过为准。 |
| 自由重新设计，参考图表达对现代感的期待 | 重新安排导航、信息层级和留白。使用 Mac 的标题栏、菜单、表格、系统字体和外观偏好。 |
| 首页由用户可自定义的小组件组成 | 交付实时速度曲线、用量统计、连接控制、节点、模式五种组件。每一种都可以添加、移除、排序和选择适用尺寸。 |
| 现有左栏四个图标挤在上方，导航方式交给设计决定 | 主窗口采用顶部文字导航，将整幅内容区域交给当前页面；独立设置窗口按自己的任务组织。 |

**本方案的设计取舍。** “小组件”指 FreeV6 主窗口内可直接操作的卡片。首版按固定列宽排列，用户决定组件、顺序和跨度。布局保存在当前 Mac 用户的本机偏好中。首次启动时先完成必要的协议阅读；之后正常冷启动默认进入仪表盘，同一次运行中从 Dock 重开窗口则回到刚才的工作位置。显式选择节点、日志或故障恢复入口时，以用户选择的目标为准。

### 原生组件调研与选型

| 用户操作 | 本版使用的组件 | FreeV6 自己负责的部分 |
| --- | --- | --- |
| 切换四个主页面、在窗口关闭后操作连接 | SwiftUI `TabView`、`MenuBarExtra` 和系统设置窗口 | 让快捷键、菜单和卡片查询同一个会话状态。[标签栏](https://developer.apple.com/documentation/swiftui/tabviewstyle/tabbaronly) · [菜单栏入口](https://developer.apple.com/documentation/swiftui/menubarextra) |
| 查看实时速度和用量占比 | Swift Charts 的 `LineMark` 和 `SectorMark` | 提供共享采样、字节单位、方向、线型，以及断开和无数据状态。[Swift Charts](https://developer.apple.com/documentation/charts) |
| 调整卡片顺序与尺寸 | macOS 27 使用 SwiftUI 的 `reorderable` 和 `reorderContainer`。旧系统使用原生拖放，所有版本均有拖动手柄和前后移动菜单 | 一列或两列的跨度、窄窗排列规则、编辑草稿和个人布局存档。此次改版没有新增第三方 UI 依赖。[Apple 的排序示例](https://developer.apple.com/documentation/SwiftUI/Reordering-items-in-lists-stacks-grids-and-custom-layouts) |

### 窗口布局

- **顶部导航。** 以原生标签页呈现「仪表盘、节点、配置、日志」。保留这四个目的地的 ⌘1–⌘4 和“显示”菜单。沿用统一标题栏、窗口红绿灯和窗口尺寸记忆。页面动作放在当前页标题的右侧。空间紧张时将次要动作收入“更多”，四个页面始终可以通过文字入口切换。macOS 15 起采用顶部标签栏，macOS 14 采用标准标签页。
- **连接状态。** 标题栏显示简短状态。显示连接卡时，卡片承载仪表盘内的主要启停按钮；移除连接卡或切到其他页面后，标题栏提供同一操作。连接准备、恢复失败等阻断项出现在网格上方，直接给出下一步。用户即使清空仪表盘，也能找到恢复网络的入口。
- **视觉。** 背景使用系统窗口色，图表放在平整的卡片表面。选中和主要操作使用强调色；成功、等待和异常同时用文字与符号区分。上传、下载分别用稳定的色彩和线型，数值使用等宽数字。沿用跟随系统、浅色、深色三种外观。支持的系统上让标题栏和导航采用系统材质，降低透明度时仍能清楚看到文字、选中态与图线。
- **窗口尺寸。** 以现有默认窗口 920 × 620 pt 和最小窗口 720 × 480 pt 为设计基准。按内容可用宽度与卡片最小可读宽度，从三列重排为两列或单列。允许纵向滚动。缩放窗口只改变显示位置，用户保存的组件顺序和首选尺寸继续生效。

## 可编辑仪表盘

默认宽布局第一行左侧放连接控制，右侧放跨两列的实时速度；第二行依次放用量统计、节点和模式。首次使用就能直接断开、切节点或切模式。偏重监控的用户可以把曲线放到第一位，也可以移除操作卡，把整页留给流量数据。

| 小组件 | 内容和动作 | 边界状态 |
| --- | --- | --- |
| 连接控制 | 显示会话状态及一个主按钮。在本人已连接的会话中单击即断开。缺少条件时，主按钮进入对应准备步骤。 | 操作中显示“正在连接”或“正在断开”，抑制重复提交。其他用户占用时显示占用原因，只提供可用操作。 |
| 实时速度 | 同时显示上下行速率、单位和带时间刻度的双线曲线。紧凑版保留最新读数，宽版展开曲线与时间范围。 | 区分“等待首个样本”、真实的零速率、读取失败和已断开；重新连接后使用新会话的样本。 |
| 用量统计 | 在“本月 / 全部累计”之间切换，用圆环表示上下行占比，旁边列出两个精确值。紧凑版以数值为主。 | 断开后仍可读历史。总量为零时显示零值和中性圆环；读取失败给出原因与重试入口。 |
| 节点 | 显示接入点、当前节点和自动或首选状态。弹出菜单切换最近使用或可用节点，完整分组、搜索和测速进入节点页。 | 根据当前会话和可用组显示选项。切换中显示进度，服务确认后更新选中态。断开时给出连接提示。 |
| 模式 | 展示规则、全局、直连。宽版直接切换，紧凑版使用带当前值的菜单。 | 对已连接会话即时生效。若会话切换成功但默认模式保存失败，分别呈现两个结果，允许进入配置检查。 |

**编辑流程**

1. 点页面右上角“编辑仪表盘”，进入独立编辑状态。停用卡片中的网络操作，卡片显示移动、尺寸和移除入口，避免拖动时误断开。
2. 点“添加小组件”，在组件目录预览内容和支持的尺寸。首版每种组件最多一张，目录标明“已添加”。“紧凑”和“宽幅”分别占一列和两列，窄窗口自动适配。
3. 拖动手柄调整顺序；也可用键盘打开卡片菜单，选择“前移 / 后移”。跨行或缩放后顺序按从左到右、从上到下读取。
4. “完成”一次保存整份布局；“取消”丢弃本轮修改；“恢复默认布局”先更新编辑预览，点“完成”才生效。移除全部组件后，空首页保留“添加小组件”、顶部导航和连接入口。
5. 偏好记录保存版本、稳定组件 ID、顺序和尺寸。首次使用载入默认布局；有效的空布局按用户选择保留。升级时保留可识别的选择、去重并修正失效尺寸，新增组件进入目录供用户添加。损坏或无法解释的记录显示可恢复的默认布局。

## 首次使用与其他页面

| 界面 | 设计及主要任务 | 验收时观察 |
| --- | --- | --- |
| 安装与首次启动 | 从 DMG 打开时展示安装指引。正常打开后保留协议、隐私阅读及同意流程。首次进入仪表盘，网格上方仅突出“完成连接准备”；详情列出网络服务、核心、账户、规则数据和配置检查的实际情况。 | 新用户能找到当前应做的一步；备用配置可用时按实际依赖跳过 WARP 步骤。取消系统授权或中途退出后，再次进入能继续。 |
| 节点 | 顶部切换分组与搜索，列表固定呈现节点、使用状态、延迟和操作。当前节点、手动首选、自动选择分别标识；保留单项测速、分组测速与停止。 | 搜索后仍能选择节点。测速中断开或重连，旧结果不会覆盖新会话。节点页与仪表盘、菜单栏显示同一选择。 |
| 配置 | 按代理规则、域名与网段、链式代理、备用配置组织。窗口中明确区分运行中的模式和下次生效的已保存配置。让“保存”和未保存提示相邻。 | ⌘S 作用于当前编辑窗口。保存失败保留输入，重新载入可取消；从设置的规则入口访问同一份编辑状态。 |
| 日志与诊断 | 给表格让出主要空间。页头保留级别、暂停/继续、导出；选中事件可复制。恢复失败时可以直达日志或导出脱敏诊断。 | 暂停显示时仍记录新事件；导出当前日志与导出脱敏诊断的名称、内容可区分。 |
| 设置与帮助 | 保留 ⌘, 独立设置窗口，按通用、代理规则、WARP 账户、核心与数据、网络服务组织。通用放外观、启动、菜单栏偏好；维护操作与日常偏好分开显示。帮助说明同步新导航和布局编辑方式。 | 开关菜单栏图标、静默启动、修复服务及取消卸载均有清晰反馈。隐藏菜单栏后可从 Dock 重开。 |
| 菜单栏与应用菜单 | 右上角保留原生菜单。上部放状态、速率和连接动作，中部放模式与节点，下部放主窗口、设置、帮助和退出。核心维护归入次级菜单。应用菜单保留检查更新和原有快捷键。 | ⌘W 收起窗口后仍可从菜单栏切模式或断开。重新打开窗口，状态一致；退出时按现有流程等待网络恢复。 |
| 公告与更新 | 维护者公告通过仪表盘页头的公告入口查看，保留未读、缓存及刷新。正在安装更新或恢复失败时，在窗口状态区展示进度或解决动作。 | 无公告不占用固定卡位；用户可以找到未读公告。清空组件后仍能看到会阻断连接的更新或恢复状态。 |

| --- | --- | --- |

| 4. 其余页面与首次使用 | 改造节点、配置、日志、设置、安装与协议页。接好准备、公告、帮助、更新和异常入口，检查快捷键与焦点。 | 从任一相关入口均能到达正确页面；草稿、自动选择、更新和网络恢复等原有行为通过回归。所有页面随同一个候选版本交付。 |
| 5. 全套验收 | 先在隔离界面测试程序重现状态，再用实际打包应用验证窗口、菜单及系统交互。运行原生测试，保存关键截图、交互结果和待验项。 | 下面的验收项目全部有结果。需要真机的项目单列设备、系统与实际结果，完成后才判定整版通过。 |

## 整版验收清单

- [ ] **首次使用。** 覆盖 DMG 安装提示、首次同意、文档变化或缺失、服务未安装、授权取消、准备未完成、具备条件后连接。
- [ ] **日常操作。** 在首页连接、切节点、切模式、查看用量；收起窗口后从状态菜单断开，通过 Dock 重开并核对状态。重复点击只执行一次。
- [ ] **个性化。** 鼠标和键盘都能添加、移除、改尺寸、排序、取消和恢复默认。清空后仍可操作连接；重启和升级后保留布局；坏记录可恢复。
- [ ] **会话与数据。** 覆盖未连接、连接中、已连接、断开中、未知、占用、恢复失败，以及无样本和零流量。模拟切换后收到旧会话回复，检查图表、节点及模式都属于新会话。
- [ ] **其他页面。** 配置保存及失败、日志暂停和导出、设置偏好、公告已读、更新恢复、帮助入口逐项通过。隐藏右上角入口后 Dock 路径可用。
- [ ] **外观与辅助功能。** 默认和最小窗口分别检查浅色、深色、键盘焦点、VoiceOver 名称与读序；用增大对比度、减少透明度和减少动态效果复验。曲线提供可读速率摘要，颜色之外仍有方向和状态信息。
- [ ] **实现与实机。** 执行 `bash scripts/macos/swift.sh test`。扩展现有隔离界面程序，使其能切换模式并覆盖首次使用、编辑布局和异常；用正式打包方式得到的候选应用复验菜单跟踪、窗口收起、后台计量和退出恢复。分别记录 macOS 14 及当前开发系统的结果，真实网络启停在授权测试环境验证。[隔离界面程序](../../../macos/Probes/InterfaceStates.swift) · [构建入口](../../../scripts/macos/build-ui-fixture.sh)

## 本次隔离验收 · 2026-11-06

在 Apple Silicon、macOS 27.0.1 上使用独立测试应用。节点、速率和会话均为模拟数据，用量读取临时目录中的账本。按本次授权，桌面操作仅限测试应用窗口，未安装系统网络服务，也未操作真实隧道和 DNS。

| 项目 | 已取得的结果 |
| --- | --- |
| 个性化 | 实际将宽幅速度卡从首位跨行拖至末位，取消后顺序还原。验证了调整尺寸、移除、从目录添加、恢复默认和退出重开后保留已保存布局。布局测试另覆盖清空、坏记录恢复和未知组件。 |
| 日常操作 | 在仪表盘切换节点与模式，再到节点页和配置页核对结果。隔离节点测速产生对应读数。模拟断开后可读取历史用量，恢复失败会显示重试和脱敏诊断入口。 |
| 主窗口和辅助界面 | 查看首次阅读、日志暂停、设置分组和外观切换。最终构建按整个窗口量得 720 × 480 pt（2× 截图为 1440 × 960 px），首行并排显示连接卡和速度曲线，滚动到底可操作工作模式。默认窗口为 920 × 620 pt。[最小窗口](../../../build/macos-ui/Previews/overview-normal-720-light.png) · [默认窗口](../../../build/macos-ui/Previews/overview-normal-920-light.png) · [编辑模式](../../../build/macos-ui/Previews/overview-editing-920-light.png) |
| 主窗口收起与重开 | 在东区节点使用中时按 ⌘W，前景切回独立设置窗口。选“窗口 → 打开主窗口”后，节点页保持选中，当前节点和连接状态一致。 |
| 后台操作及辅助功能 | 主窗口收起后，从隔离应用中复用正式状态菜单组件的预览执行模拟断开。菜单变为“未连接”，再次打开主窗口仍在节点页，标题栏的辅助功能读数同步为“未连接”。从菜单重新连接后，读数变为“已连接”，节点列表恢复。 |
| 构建及回归 | 152 项 Swift 测试全部通过，零跳过。宽幅速度卡在两种窗口宽度下均有回归测试，验证首行两卡并排、行高一致、右缘对齐。产物位于 `dist/macos/FreeV6.app`，隔离版位于 `build/macos-ui/FreeV6 UI Fixture.app`，两者均通过 `codesign --verify --deep --strict` 本地签名完整性检查。[回归日志](../../../build/macos-ui-tests.log) · [打包日志](../../../build/macos-ui-release.log) |

整版清单包含后续发布验收。macOS 14 实机、系统辅助功能组合、直接操作系统右上角菜单和正式包真实网络连接单列；本次结果不作为这些项目的通过记录。
