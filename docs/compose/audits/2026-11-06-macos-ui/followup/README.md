# FreeV6 macOS · 第二轮界面反馈与验收

2026-11-06。此次覆盖仪表盘、节点、日志和窗口工具栏。截图来自与正式客户端共用界面代码的隔离预览。预览使用本机 worker 保存测试配置和历史，网络会话、测速与流量采样使用模拟数据。

| 反馈 | 修复与判断依据 | 如何验收 |
|---|---|---|
| 1. 断开后不能选模式、看节点，实时速度消失 | 原来三者都依赖运行会话。现在断开后，规则、全局、直连直接写入下次默认值；节点来自本地配置或标明来源的上次列表，可预选或恢复自动选择。重连后重新核对实际节点组，再显示服务确认的结果。速度卡保留上下行图标和基线，无样本用「—」，实测为零才显示「0 B/s」。 | [未连接仪表盘](02-offline.jpg)；已实测离线选全局、西区，退出重开仍保留，重连后变为「当前工作模式，全局」「西区 · 使用中」。零速率场景上下行均为 0 B/s。 |
| 2. 按键没有动画 | 电源、模式、周期、节点选择与右上角动作提供按下与释放反馈；模式选中背景、用量周期下划线随选择移动。系统开启「减少动态效果」时保留状态与按压明暗反馈，跳过位移动画。 | 长按再松开电源；切换「规则 / 全局 / 直连」和统计周期。离线时操作不会把界面切成「已连接」。 |
| 3. 用量周期和小字 | 「本月 / 累计」改成文字标签，以字重和下划线指示选中。大号数字是该周期的总用量，保留下方上下行拆分；移除重复的年月和「累计用量」小字。读屏仍包含周期、总量、上下行。 | [累计视图](06-offline-total.jpg)。首次启动的示例只有本月流量，因此两个周期可能显示同一数值；数据分别来自月报与累计计数。 |
| 4. 顶栏切页卡顿 | 顶栏固定一组原生按钮，只有选中底板移动；连续点击时从正在显示的位置接着移动。已访问页面保留，导航与实时速率各自更新，速度采样不再触发整窗重绘。 | 用鼠标或 ⌘1–⌘4 连续切页；节点搜索后前往日志再返回，搜索词仍在。下文记录了快速切页的实际延迟。 |
| 5. 节点页层次和操作不清 | 页首先说明「当前使用」或「下次连接」。列表一行对应一个节点，选用节点与测速各有入口。状态文字区分「使用中」「首选」「预选」。离线能搜索和选用；只有联网才提供即时测速。 | 对照 [720 pt 离线节点页](03-offline-nodes-720.jpg) 和 [在线节点页](04-online-nodes.jpg)。仪表盘的「更换节点」也能直接搜索与选择。 |
| 6. 顶栏右侧状态和操作难辨 | 状态点和文字为只读信息，旁边只有一个明确动作：连接或断开。读屏状态随会话更新。固定布局使两个状态下都能从同一处操作。 | 对照 [已连接](01-connected.jpg) 和 [未连接](02-offline.jpg)；已核对按钮与辅助功能树中的状态同步。 |
| 7. 日志需要清空 | 「清空…」先说明范围，确认后清空全部级别、暂停快照和已保存的本机应用事件；已导出文件及系统服务日志保留。新事件照常记录，迟到的旧事件不会把历史补回。 | 进入日志（⌘4），点 [清空…](05-log-scope.jpg)。实测测试历史清为 0 条，随后产生新的连接事件。 |

**本机复测入口。** 已构建的独立预览位于 `build/macos-ui/FreeV6 UI Preview.app`。既有 `FreeV6 UI Fixture.app` 入口也已重新构建；两个应用有各自的测试数据。手动复验可从「测试场景 → 未连接」开始，先选全局和西区，再点右上角「连接」；日常流量、代理与 DNS 均不经过预览。

**导航测量。** 在这台 arm64 Mac 的 720 pt 窄窗下，隔离预览按约 105 ms 间隔轮换四页共 32 步。最终一次主线程显示回调采样有 304 个间隔：中位数 8.3 ms，95 分位 30.6 ms，最长 85.9 ms，超过 50 ms 的有 2 次。本轮较早实现的一次记录为中位数 8.3 ms、95 分位 40.2 ms、超过 50 ms 的有 11 次。这是两次本机压力采样，不是 GPU 帧率或跨机器的流畅度保证；仍可看到个别长帧。「测试场景 → 连续切页检查」可重跑，结果写到预览包旁边的 `navigation-frame-sample.txt`。

**验证边界。** 原生套件 164 项全部通过，覆盖离线选择持久化、重新连接时校验节点、受保护阶段禁用、有冲突的配置、清空期间的新记录、旧记录重放以及失败重试。未启用真实系统代理或隧道，也未在 Intel 或 macOS 14 设备上测试。
