P0/P1 到此结束，供体验后决定下一步。Release 包使用 Flutter 3.47.6 / Dart 3.13.5，最低 macOS 14。已在 Apple Silicon 上实际打开。保留原 FlClash 连接按钮的形状变化、Prism 侧栏指示器、三段模式控件和每个方向独立的曲线；原代码固定版本、修改范围和许可见[来源清单](../../../../../apps/macos/flutter_ui/vendor/UPSTREAM.md)。

| 实际体验 | 本次看到的结果 |
|---|---|
| 断开 → 全局 → 西区 | 首页仍为「未连接」，主卡展示「下次连接使用」；上传、下载图标均保留，无采样为「—」。[断开预选](offline.jpg) · [节点选择器](node-picker.jpg) |
| 完全退出 → 重开 → 再连接 | 重开仍是未连接、全局、西区；连接完成才显示「当前接入节点 · 西区」，节点列表标记「使用中」。 |
| 在线零速率、周期切换 | 「在线零速率」下两个方向都显示 0 B/s。「本月」的示例总量为 422 MB；「累计」为 9.6 GB，上传、下载及其口径一起改变。 |
| 原图宽窗 / 浅深色 / 窄窗 | 1232×780 首行 2:1:1，模式条和主卡对齐；720×480 侧栏默认折叠，首行连接卡，下方为上传和下载；920×620 中在减少动态效果下切至节点页。大小为逻辑像素。[浅色首页](wide.jpg) · [深色首页](dark.jpg) · [深色窄窗](compact-dark.jpg) · [中等节点页](medium-nodes.jpg) |
| 顶栏与日志 | 切到节点或日志页，右上仍有「断开」；打开「清空…」先说明会清空哪些预览记录，仍可取消。窄窗的组件测试另验证拖动正文后顶栏坐标不变、仍可点顶栏断开。 |

[7 项 Flutter 测试记录](../../../../../build/flutter-toolchain/p1-flutter-test.log)：包括宽窗几何、窄窗固定控件和离线预选、重开持久化、键盘选节点、测速不误选、旧会话结果不覆盖新状态。应用与测试代码静态检查通过。构建脚本验证签名、标识与权限；体验包只使用应用沙盒权限。

录屏取自实际 macOS Release 窗口，展示断开、点击全局、打开选择器、选择西区。窗口采样率受录制工具限制，这段视频用于查看交互过程，不是帧率基准。截图左上角若显示紫色系统屏幕共享标记，它属于录制环境。官方 Mac 窗口裁自 [FlClash v0.9.3 官方图](https://github.com/chen08209/FlClash/blob/be84736605527034689c95bf27828ff27d912c5e/snapshots/preview.png)。

所有节点、流量、用量、测速、日志都是隔离演示数据。真实连接、订阅和配置导入、独立设置窗、菜单栏宿主及系统代理/DNS 不在 P1 范围；对真实流量下性能、系统服务和发行包的验收留给后续阶段。
