# 0.5.6 · 首次配置、授权复用与节点下载测速

候选版本：0.5.6（build 5），Apple Silicon，macOS 14+。

## 行为

- 首次同意协议后进入五步引导：服务、核心、规则数据、账户、配置检查。一次开始后自动串行推进；服务已就绪、资源已校验时复用，失败和暂停后可继续；检查通过后才允许完成并连接。小窗口固定底部操作区，内容可滚动。已有可用安装迁移时不强迫重走引导。服务与恢复页面保留维护操作，并预留 32 pt 标题栏空间、限制内容宽度。
- 沿用稳定本机签名。钥匙串数据仅在本次进程内短暂缓存（最多 5 分钟）；每次复用核对条目 revision、修改时间及所属钥匙串解锁状态。外部更换、删除和锁定会使缓存失效。后台调用不召唤授权 UI；不保存密码或另存明文凭据。网络服务安装与升级的必要系统授权仍保留。
- 节点页区分“整组测延迟”和单节点下载。下载显示 MB/s、取消按钮，悬停可看时间与数据量。固定 HTTPS 下载请求最长 10 秒、最多 32 MiB；一个测试并发，不自动测速。独立认证入站与隐藏选择组使测试不修改当前节点；测试前后核对入站属于会话核心。结束、取消或失败后复位 REJECT，迟到结果不跨会话展示。

## 验证

- Swift 全量 190 项通过；新增/扩展检查涵盖完成条件、状态持久化、会话内测速结果与当前节点不变、消息参数和结果边界。
- 私有临时钥匙串 12 项回归通过。直接计数确认重复读取不再请求敏感数据；外部版本替换/删除、锁定、取消及注册失败保存重试仍通过。
- Flutter 全量 25 项通过；新增最小窗口、浅色/深色、1.3 倍文字、开始/暂停/继续/完成连接，以及下载/取消/结果单位交互用例。Dart 对 lib/test 分析无问题。
- [实际窗口截图](visual/)：1232×780 与 720×480，浅色/深色，首次配置完成和下载结果。截图来自独立 QA 身份；数值为测试数据，不代表真实校园速度。
- [固定核心真实下载探针](download-loopback.json)：本地 TLS + 两个独立代理节点。正常、取消、超大响应、HTTP 错误、限时部分下载、非法节点共 6 场景通过；未认证返回 407。5 个有效请求全部经过 B，A 为 0；正常选择保持不变；测试组结束后复位。全程普通用户、回环地址，不开启 TUN，不改系统 DNS/代理，不使用真实凭据。
- 可重复入口：`scripts/macos/probe-download.py --core build/macos-probes/mihomo-darwin-arm64 --client build/macos/out/Products/Debug/freev6-probe`。原始回归日志在 `build/setup-download`。

真实校园网络速度、此次安装的系统授权次数由用户覆盖安装后验收；开发测试未切换或停止正在使用的正式连接。

## 接口依据

使用固定 mihomo v1.19.31 的 [HTTP 入站](https://github.com/MetaCubeX/mihomo/blob/v1.19.31/listener/inbound/http.go) 和 [指定出口字段](https://github.com/MetaCubeX/mihomo/blob/v1.19.31/listener/inbound/base.go)。固定下载目标采用 Cloudflare 官方 [speedtest 下载 API](https://github.com/cloudflare/speedtest/blob/main/README.md)。
