# 0.5.7 · 整组下载测速与节点排序

候选版本：0.5.7（build 6），Apple Silicon，macOS 14+。

## 行为

- 移除节点页的下载测试说明小字；保留单节点下载按钮和“整组测延迟”。
- “整组测速”依次测试当前分组全部真实节点，不受搜索筛选影响，不包含“自动选择”。全局仅一个下载队列，显示已完成数量，支持停止；单个节点失败后继续，取消或会话变化后不启动后续节点。已完成结果保留，不切换正在使用的节点。
- 排序菜单提供名称自然顺序、下载速度从高到低、延迟从低到高；同值以名称排序，未测或失败项排在后面，“自动选择”置顶。结果更新时同步排序并保留键盘高亮对应的节点。
- 复用上一版的独立测速通道，每个节点最多 32 MiB、下载请求最长 10 秒。没有后台自动测速。系统服务协议与安装权限流程未变。

## 验证

- Swift 全量 193 项通过。新增队列串行、失败后继续、取消中断后续项、会话失效丢弃迟到结果；扩展真实 worker 集成用例，检查空列表、重复或未知节点被拒绝，整组完成且当前节点不变。
- Flutter 全量 30 项通过，Dart lib/test 静态分析无问题。覆盖三种排序、名称数字自然顺序、未知结果末尾、自动选择置顶、搜索下仍测试全组、进度与取消、实时排序保留键盘目标、浅色/深色最小窗口和 1.3 倍文字。
- 视觉检查使用隔离 QA 应用、独立身份和测试节点，不修改当前正式应用、代理或 DNS。实际窗口截图见 visual/；截图中的速度为测试数据。

原始验证日志保存在 build/node-batch。真实校园节点的批量下载表现留给安装后的网络环境验收。
