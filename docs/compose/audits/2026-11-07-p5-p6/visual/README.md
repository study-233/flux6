## 键盘和读屏

- 通过真实 AppKit 菜单发送 ⌘2、⌘F，实际节点搜索框取得焦点。处理了系统默认“查找”菜单与产品快捷键的冲突。选择器中方向键改变目标、Return 确认、Esc 取消；控件测试核对关闭后的焦点归还。[节点选择器](node-picker.png)
- 在独立 QA 应用首次渲染前接入其 Flutter 原生辅助功能桥，直接遍历 AppKit 窗口提供的元素。系统 VoiceOver 保持关闭。离线首页和在线首页各有 37 个原生元素，640 pt 设置窗有 34 个，28 节点页面有 59 个。每个结果同时记录 Flutter 与 AppKit 两份树。[首页及浮层](main-tree.json) · [长节点](long-tree.json) · [独立设置窗](settings-tree.json)
- macOS 会把被动文本的 label 作为 AXStaticText 的值。速率方向、实际数值、峰值与周期合并到同一个可读名称，离线则明确写「暂无采样」。有采样的零值另有控件回归。模式与用量周期在当前项的可读名称中说明「已选中」。搜索框属于名为「搜索节点」的原生组，节点项自身提供名称和「使用中」状态。日志确认框向系统提供覆盖的记录范围、取消和清空全部两个动作。[日志确认画面](clear-logs.png)
- 这次检查可供读屏使用的原生名称、角色和值。VoiceOver 的实际语音、声音提示和朗读顺序由用户试听。关闭减少动态效果后的视频来自 22 次连续 Release 渲染采样，保留每次采样的实际时间间隔；帧时统计单独见[性能报告](../performance/README.md)。

## 复查

在项目根目录依次运行以下命令。脚本编译独立 QA 镜像，以临时身份和会话子进程驱动正式的 HostApplication 页面，不写正式应用数据。编译入口和 QA 通道只存在于该隔离镜像。

```sh
bash scripts/macos/probe-flutter-visual.sh build
bash scripts/macos/probe-flutter-visual.sh run
```
