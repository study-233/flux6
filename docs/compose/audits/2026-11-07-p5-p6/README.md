# FreeV6 0.5.3（build 2）· macOS 本地验收

Apple Silicon，最低部署目标 macOS 14。实测机器为 macOS 27.0.1 的 M5 Pro。应用使用正式标识 `dev.freev6.desktop` 和原有数据路径，打开时可读取旧版设置。这次在临时用户目录中验证了迁移与回退。若要在有重要配置的机器上覆盖旧版，请先断开、确认网络已恢复，保存旧 App 并按原有备份流程备份设置与用量。

**只测界面**　双击[独立 UI 体验应用](<../../../../build/macos-ui/FreeV6 Flutter Integration.app>)。此包已按最终界面重建，使用单独的数据目录、真实 Go worker 与隔离会话，不需要管理员权限，可以直接试花形启停按钮、切页、模式、速率、节点预选与日志清空。也可以先看[原图对照](visual/compare.html)。

**测正式安装及升级兼容性**　双击 DMG，把 FreeV6 拖入 Applications，推出镜像，再从“应用程序”打开。直接从镜像打开只会显示安装提示。当前为 ad-hoc 本地签名，本机没有 Developer ID 或 Apple 公证。Gatekeeper 在默认分发检查中拒绝此包。如果系统阻止运行，请保留安全设置，使用已公证的发行版本或在允许本地测试的环境中验收。
## 验收路线

| 操作 | 可以直接观察到的结果 |
|---|---|
| 先断开，逐个点「规则」「全局」「直连」。打开「接入节点」，预选一个已配置的节点。完全退出后重开。 | 三个模式互斥。已知节点可浏览和预选；重开保留选择。没有本地节点时先在配置中准备好节点。上传、下载图标仍在，无样本显示「—」，有真实零样本显示「0 B/s」。 |
| 在「节点」按 ⌘F，输入名称；从首页打开选择器，试方向键、Return、Esc。 | 搜索焦点落在输入框，列表按关键词过滤。方向键移动目标，Return 确认，Esc 取消并将焦点还给打开选择器的控件。长中文名不会撑破卡片。 |
| 看宽窗首页，再缩到 720 pt，滚动并用 ⌘1–⌘4 来回切页。用鼠标或触控板拖标题栏。 | 宽窗首行是连接卡和两个速率卡。窄窗卡片换行，标题和会话入口固定；尽管内容滚动仍可操作。请亲手确认标题栏能随指针移动，记录发生卡顿的窗口尺寸。 |
| 切换用量「本月 / 累计」，再打开设置并切换外观、减少动态效果。 | 数字和分项随周期变化。设置来自左侧栏底部或 ⌘,，独立窗口有自己的侧栏；缩窄后仍可操作。减少动态效果后，对比按键与页面切换。 |
| 按 ⌘4 进日志，切换筛选或暂停后点「清空…」，先取消再确认。 | 确认文字说明涵盖全部级别和暂停期间记录。取消保留旧记录，确认后清空；之后产生的新事件照常显示。 |
| 自行开启 VoiceOver，用 VO＋左右键依次访问侧栏、三个模式、节点、速率和清空日志确认框，结束后恢复自己的设置。 | 重点听方向、数值或「暂无采样」、选中的模式与节点，以及清空的范围。本次验证了 macOS 导出的实际元素，语音、朗读顺序和听感留给你。 |

## 有真实校园网络时再测

1. 在可恢复的测试环境先记录已有代理、DNS 和网络连通性。如果有常驻代理软件，记录它当前的设置；本机预检已有 HTTP、HTTPS、SOCKS 代理。
2. 用候选版的设置准备所需配置，在「网络服务」页面按系统提示安装服务并授权。留意升级后的钥匙串请求，只在核对应用和条目名称后决定是否授权。取消后可重试。
3. 断开时选好模式和节点，连接后核对「使用中」节点、上下行曲线和日志，访问实际需要的网络目标。断开并完全退出，再核对原代理、DNS 和原网络访问是否恢复。
4. 确认网络恢复后再进行替换或回退。若恢复失败，保留应用并使用恢复流程，导出对应时段的日志。

本次没有执行正式系统服务安装，也没有接管本机代理、DNS 或校园隧道。macOS 14 真机、干净安装环境、实体拖窗手感和 VoiceOver 试听仍待验收。候选没有在线公开更新源；Sparkle 的升级实验使用了隔离签名源。
