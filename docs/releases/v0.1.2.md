# Flux6 0.1.2

- Android 的网络速度卡片用曲线显示实时上传和下载速度，点开可查看本月和累计用量。
- Windows 修复了短连接流量漏计，本月和累计用量会计入两次采样之间已经结束的连接。
- Windows 可按当前网络的测速结果自动选点，也可手动固定节点、整组测延迟和下载速度。
- macOS 默认在启动时检查更新，安装前会询问是否安装并重新打开，可在通用设置中关闭启动检查。
- macOS 在后台网络服务的启动配置丢失时可重新安装配置并恢复服务。
- Android 可直接从正式发行页下载更新，由系统核验签名并提示安装。

Android 0.1.1 用户请手动覆盖安装本次 APK，之后可在应用内更新。
