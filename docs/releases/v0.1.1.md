# Flux6 0.1.1

macOS 和 Android 从这个版本开始支持应用内更新。使用 0.1.0 的用户需手动安装一次 0.1.1。

| 平台 | 首次升级 | 之后如何更新 |
| --- | --- | --- |
| macOS 14 及以上，Apple Silicon | 退出 Flux6，打开 `Flux6-0.1.1-macos-arm64.dmg`，将 Flux6 拖入“应用程序”并替换旧版。 | 在 Flux6 菜单或“设置 → 通用”中点“检查更新”。应用会验证更新签名，再提示安装。 |
| Android 7.0 及以上，ARM64 | 打开 `Flux6-0.1.1-android-arm64.apk`，按系统提示覆盖安装。 | 在“关于”中点“检查更新”，或在通用设置启用自动检查。下载完成后点安装提示，由系统确认安装。 |

本次提供 macOS build 12 和 Android build 2026111201。试用过早期 0.1.1 的用户，macOS build 11 可在新清单上线后检查更新，Android build 2026111101 可手动覆盖安装同版本的新 APK。

两端沿用 0.1.0 的应用 ID 和签名证书。可用附件中的 `SHA256SUMS` 校验下载文件。

## Windows x64

Windows 首个正式版也使用 0.1.1。首次安装或从 0.5.x 开发版迁移时，请先退出客户端，再运行 [Tauri 安装包](https://github.com/study-233/flux6/releases/download/v0.1.1/Flux6-0.1.1-windows-x64-setup.exe)。之后每次启动都会检查更高版本，由用户选择下载并确认安装。

Windows 安装包和对应源码由 [GitHub Actions](https://github.com/study-233/flux6/actions/runs/43686886905) 从提交 [911f28d](https://github.com/study-233/flux6/commit/911f28dbf5cbe0c893d318f9a3ef9f7550ac079d) 构建，作为补发附件加入同一 Release。Windows 附件摘要见 [Windows-SHA256SUMS](https://github.com/study-233/flux6/releases/download/v0.1.1/Windows-SHA256SUMS)。
