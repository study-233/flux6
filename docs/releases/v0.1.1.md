# Flux6 0.1.1

macOS 和 Android 从这个版本开始支持应用内更新。使用 0.1.0 的用户需手动安装一次 0.1.1。

| 平台 | 首次升级 | 之后如何更新 |
| --- | --- | --- |
| macOS 14 及以上，Apple Silicon | 退出 Flux6，打开 `Flux6-0.1.1-macos-arm64.dmg`，将 Flux6 拖入“应用程序”并替换旧版。 | 在 Flux6 菜单或“设置 → 通用”中点“检查更新”。应用会验证更新签名，再提示安装。 |
| Android 7.0 及以上，ARM64 | 打开 `Flux6-0.1.1-android-arm64.apk`，按系统提示覆盖安装。 | 在“关于”中点“检查更新”，或在通用设置启用自动检查。下载完成后点安装提示，由系统确认安装。 |

本次提供 macOS build 12 和 Android build 2026111201。试用过早期 0.1.1 的用户，macOS build 11 可在新清单上线后检查更新，Android build 2026111101 可手动覆盖安装同版本的新 APK。

两端沿用 0.1.0 的应用 ID 和签名证书。可用附件中的 `SHA256SUMS` 校验下载文件。
