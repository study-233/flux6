# Flux6 0.2.0

- Android、macOS 和 Windows 统一使用 FlClash v0.9.5 界面和内置 MASQUE 核心。
- 首次启动并同意注册后，Flux6 会自动准备 WARP 配置，随后即可手动连接。
- 默认 WARP 接入点支持具有 IPv6 出口的 Wi-Fi 和移动网络。
- 三端的本地混合代理端口统一改为 `17890`，HTTP 和 SOCKS 客户端均可连接 `127.0.0.1:17890`。
- 仪表盘新增流量统计卡片，圆环显示本月上传和下载占比，点开可切换本次连接、本月和累计，并比较三个周期的用量。

从 0.1.x 升级前，请先断开连接并退出旧版，macOS 用户请下载 DMG 覆盖安装。首次启动 0.2.0 会清空旧配置、凭据和用量历史。
