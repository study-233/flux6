# Flux6 0.1.4

- Windows 恢复连接详情、DNS 查询、服务状态和出口信息等 FlClash 常用功能。
- Windows 设置支持修改 Mixed、HTTP、SOCKS 和 DNS 端口，以及免流所需的 DNS/TUN 选项。
- 修复 Windows 无法手动切换中文或图标名称节点的问题。
- 自动优选融入节点卡片，优选策略、下载测速和历史记录分栏展示，切换中避免重复操作和旧状态覆盖。
- 修复 Windows 启动时「连接后台服务」页面的异常样式，连接失败后可重试。

本次仅更新 Windows，请从本发布页下载安装；从 0.1.3 升级继续保留原配置和界面偏好。
