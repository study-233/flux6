# Mac 客户端的数据与发布说明

**本机存储。** Flux6 将 WARP 凭据保存在当前用户的 macOS 钥匙串。链式代理和备用配置的敏感字段使用钥匙串里的独立密钥加密。设置与流量统计保存在 `~/Library/Application Support/dev.freev6.desktop`，下载缓存和日志分别位于 `~/Library/Caches/dev.freev6.desktop` 和 `~/Library/Logs/dev.freev6.desktop`。

**后台服务。** 界面通过私有管道与业务进程通信，通过 XPC 连接管理员安装的网络服务。服务在 `/Library/Application Support/dev.freev6.desktop` 管理核心及会话恢复记录。断开连接后，服务负责恢复本次会话的 DNS。可以在设置中卸载网络服务，并在 WARP 页单独删除本机凭据。

**启动与网络请求。** 同意协议后，应用会读取 `study-233/flux6` 仓库的公告。备用配置默认关闭；未来从同一仓库的 `profiles/` 目录获取已公开的节点，或使用你明确导入的来源。进行 WARP 连接或检查连接配置时，会自动读取已有凭据；确认没有凭据后，才会请求 Cloudflare 注册 WARP 设备并保存到钥匙串。使用备用配置时不注册 WARP。选择自动连接后，应用会在启动时执行同样的准备和连接流程；钥匙串需要授权时，本次后台尝试会停止，不弹出授权窗口。注册成功但保存失败的凭据暂存在本次应用进程中，可在 WARP 账户页重试保存。普通模式连接前会向 `api-ipv6.ip.sb` 查询本机对外 IPv6 地址，用于判断校园网范围。开启登录启动会在当前用户的 `~/Library/LaunchAgents` 添加 Flux6 登录项，可在“设置 → 通用”中关闭。

**节点下载测速。** 仅在你手动点击测速时，通过所选节点向 `speed.cloudflare.com` 请求测试数据。每次下载请求限时 10 秒，最多接收 32 MiB 测试数据，可随时取消；结果和时间保留在当前应用会话中。测试不会切换当前节点，不上传文件或账户凭据。已授权读取的凭据最多在进程内复用 5 分钟，复用前检查钥匙串锁定状态和条目版本，不另存明文文件。

**发布来源。** 原项目仓库为 `evansrrr/free-v6`。这个 Mac 客户端的发行仓库为 `study-233/flux6`。配置了正式通道的版本会在你检查更新时向 GitHub 请求对应架构的签名清单与安装包。

下文保留上游隐私政策全文。其中关于 `state/warp.json`、安装目录、回环 HTTP 接口和卸载器复选框的示例适用于 Windows 客户端。Mac 的存储、进程通信和卸载入口见上面的说明。
