FreeV6 0.5.7（build 6）· macOS 本地候选版

节点页新增“整组测速”和排序菜单，移除原先的下载说明小字。整组测速按顺序测试当前分组全部节点（不受搜索筛选影响），显示已完成数量，可随时停止并保留已完成结果；单个失败后继续。可按下载速度从高到低、延迟从低到高、名称自然顺序排列，未测或失败的结果放在后面，自动选择保持置顶。

本版新增首次配置引导：同意协议后，按顺序安装网络服务、准备核心与规则数据、读取或注册账户、检查配置，完成后即可连接。已准备的资源会复用，中断后可继续。维护操作保留在“服务与恢复”和设置中。

已授权读取的钥匙串凭据在本次应用进程中短暂复用；每次复用都会检查条目版本、修改时间及钥匙串锁定状态。沿用固定本机签名证书，减少反复读取和更新版本引起的授权。本次升级更新网络服务仍可能需要一次管理员授权；系统锁定或旧签名条目迁移仍按 macOS 要求授权。

节点页保留“整组测延迟”和每个节点的下载图标。连接后点击即可测试节点的平均下载速度（MB/s），再次点击停止图标可取消。测试使用独立通道，不切换当前节点；每个节点单次最多下载 32 MiB 测试数据，下载请求限时 10 秒，会产生真实流量。测速时间和已下载数据量可悬停结果查看。

适用于 Apple Silicon（M 系列）和 macOS 14 或更高版本。本机验收使用 Apple Silicon 和 macOS 27.0.1。

1. 核对候选 DMG 的来源和 SHA-256。双击 DMG，将 FreeV6 拖至旁边的 Applications（应用程序）文件夹，再推出映像。在映像内打开 FreeV6 时会显示安装指引。当前候选使用固定的本机自签名证书，尚未获得 Developer ID 签名或 Apple 公证。Gatekeeper 阻止运行时，可先核对来源与摘要，或等待已公证的发行版本。Apple 关于开发者身份验证的说明：https://support.apple.com/zh-cn/102445 。

2. 从“应用程序”打开 FreeV6，阅读协议与隐私政策。左侧栏底部的“设置”也可用 ⌘, 打开。先在断开状态测试“规则 / 全局 / 直连”及接入节点预选；退出重开后检查选择是否保留。节点列表以本地配置或当前会话为准。

3. 测试真实连接前，请在方便中断网络的测试环境记下当前系统代理及 DNS。首次使用按配置引导完成准备即可；升级已有安装时，若提示服务需要更新，可在“设置 → 网络服务”修复一次。自定义规则仍可在“配置”页修改并保存。

4. 花形按钮启动连接。普通模式检查校园 IPv6；服务确认连接后，“使用中”标识当前节点。“节点”页可搜索、切换、测延迟和下载测速；测试另一节点不会选择它。若连接失败，可到 macOS 菜单栏“连接 → 服务与恢复”查看原因。连接后关闭主窗口可保留会话，从 Dock 或菜单栏可再次打开；退出会尝试先恢复本人会话。

5. 点“断开”后确认会话停止，并对照连接前记录复查系统代理与 DNS；如果提示“待恢复”，可留在应用内重试恢复并查看日志。在其他用户占用状态下，请由会话拥有者处理。

6. “配置”页支持导入本地文件或订阅地址。链式代理与备用配置分别管理；维护者公告和已保存配置决定可用操作。升级后，系统钥匙串可能要求重新授权新版读取已有 WARP、链式或备用凭据。请核对应用和条目名称再决定是否允许；取消后可重试。

7. 按 ⌘4 进入“日志”，用页内工具栏筛选、暂停、导出或清空。清空需要确认，新事件仍可写入。从 macOS 菜单栏“导航 → 编辑首页布局”可以调整或恢复仪表盘。

8. “设置 → 通用 → 应用更新”提供检查更新入口。本候选的公开更新通道尚未配置，手动测试请使用随附 DMG。隔离测试已验证带临时签名通道的升级与失败恢复。需要回退时，先断开并确认网络恢复，再备份配置和用量数据，退出后替换为已验证的前一版。

9. 卸载前如已开启登录启动，请先在“通用”中关闭。断开会话并确认恢复后，在“网络服务”中卸载已安装服务，随后退出并移除应用。

组件许可、对应源码说明及输入文件哈希见 FreeV6.app/Contents/Resources/Notices。真实管理员安装、校园隧道、实际系统代理/DNS 恢复及 VoiceOver 试听留给本机最终验收。
