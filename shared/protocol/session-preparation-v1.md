# macOS 会话准备记录 v1

这是网络服务内部的磁盘格式，不是 XPC 协议，也不接受客户端提供的恢复记录、目标路径、文件名或 session ID。当前 XPC v3 的配置检查仍只做内存复验；准备存储已由 `ServiceResourceStore.prepareSession` 接入，等待启动协调器调用。

## 所有权与目录

- `/Library/Application Support/dev.freev6.desktop/network.lock`：会话存储持有的内核文件锁，安装、升级、卸载和安装事务恢复共用。安装工具在取得该锁后检查恢复记录，避免检查与会话创建之间的竞态。
- `network-session.json`：0600、服务所有、单链接普通文件，不含私钥、节点或完整配置；先写入并同步，再创建会话目录。
- `sessions/<服务生成的 UUID>/`：0700、服务所有；拒绝所有 allow ACL，包括只读或遍历授权，保留无此类授权的目录。生产所有者为 root，用户 UID 只用于会话归属，不能成为文件所有者。
- 会话内固定名称：`mihomo`（0500）、`GeoSite.dat`/`geoip.dat`/`country.mmdb`（0400）、`config.json`（0600）。配置中的 Unix socket 指向同一目录的 `c.sock`，路径必须少于 104 个 UTF-8 字节。

资源复制时核对编译时摘要、大小和架构，发布前复读新副本。使用独立 inode，不硬链接共享资源或引用用户缓存。配置由服务组装并记录 SHA256；调用启动前的验证入口时再次检查文件集合、资源内容/权限和配置摘要。该验证不是可复用的启动授权；启动仍需完成自己的持久化意图、进程身份和 DNS 事务。

## 记录与顺序

记录大小上限 4096 字节，精确字段为 `schema: 1`、`sessionID`、非零 `clientUID`、`runtimeID`、`geodataID`、`settingsRevision`、`credentialRevision`、`policyVersion`、`phase` 和可选 `configurationSHA256`。

1. 持有全局网络锁，拒绝已有记录或无法解释的会话目录。
2. 校验业务/资源 ID，检查 socket 路径长度，在内存中组装配置。
3. 原子持久化 `preparing`，此时不能有配置摘要。
4. 以排他创建方式建立 UUID 目录，复制并复验可信资源，写配置并同步。
5. 原子持久化 `prepared` 和配置摘要。再次准备不会覆盖已有记录。

v1 的两个阶段均禁止启动核心或改变系统网络。接入 `-t`、真实核心启动和 DNS 前，必须扩展记录来表达进程启动意图与副作用，处理记录前后崩溃的窗口；不能在 v1 记录下启动进程后仍将它当作无副作用的准备数据清理。

## 清理与拒绝

普通会话取消必须同时匹配 session ID 和已认证 UID；root 管理调用不能伪装成普通业务用户。内部准备恢复仅适用于本 schema 的两个已知阶段，不向 XPC 暴露任意清理入口。

恢复先验证完整记录及目录内容，只处理该 UUID 下的五个固定普通文件和合法 `.staging-<UUID>` 普通文件。先验证全部条目，再逐项删除、同步目录、核对目录 inode 后移除空目录，最后删除并同步记录。各步骤中断后可重复执行；记录存在但目录尚未创建或已删除也可恢复。

未知 schema/phase/字段、错误归属、未知文件、符号链接、硬链接、子目录、其他会话或无记录的孤立目录均保留并报错。不能以“没有找到 PID”或“当前没有网络连接”推断这些内容可以删除。安装工具在记录存在时拒绝安装恢复、替换与卸载，直到后续明确的网络恢复流程完成。

## 验证范围

`PreparedSessionStoreTests` 使用真实固定资源验证独立副本、配置绑定、UID 隔离、权限/ACL、损坏拒绝和准备中断恢复；安装测试覆盖网络锁在记录尚未写入前的互斥。

`scripts/macos/probe-sessions.py` 使用仅 Debug 提供的普通用户宿主，分别在 `preparing` 和 `prepared` 后 SIGKILL，确认活跃锁拒绝第二进程、崩溃保留记录、新进程释放锁后恢复及重复清理。公开合成凭据不会用于联网。该验证未覆盖 root 跨用户隔离、已启动核心、TUN/DNS 恢复或最低系统。
