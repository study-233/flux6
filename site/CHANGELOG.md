# Flux6 发行记录

## v0.1.1 (2026-11-12)

**Features**
- **macOS** 在菜单或“设置 → 通用”检查更新，验证更新清单和安装包签名后安装并重启。
- **Android** 在关于页手动检查更新，也可启用启动时检查。下载的 APK 通过 SHA-256 校验后，由系统提示安装。
- **首次升级** 使用 0.1.0 的用户需手动安装一次 0.1.1。

## v0.1.0 (2026-11-10)

**Features**
- **Flux6** 统一项目、客户端与安装包名称；保留原签名、包 ID 与已有配置。
- **macOS** 首个公开正式版本，支持 Apple Silicon 与 macOS 14 及以上，提供 DMG、应用 ZIP 和 Homebrew 安装。
- **Android** 首个公开正式版本，支持 ARM64 与 Android 7.0 及以上，提供 APK 安装包。
- **连接** 提供校园 IPv6 连接、节点选择与 WARP 出口管理。
- **开源** 每个平台的安装包均配有对应源码归档。

**Bug Fixes**
- **macOS** 未持有网络会话且服务安装不完整时，允许正常退出；保留已有会话的恢复检查。
